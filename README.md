# Лавка — Frontend (РК1)

Клиентская часть сервиса объявлений «Лавка» (SPA на нативном JS + Handlebars).

## Запуск

```bash
npm install
npm start
```

По умолчанию сервер запускается на `http://localhost:3000` (можно переопределить через переменную окружения `PORT` в `.env`).

## Линтер

```bash
npm run lint
```
